# Code of conduct

Be kind and be useful. Disagree about the work, not about the person. No harassment, no insults, no posting other people's private details. Bug reports that say "this does not work" without details are fine, we will ask. Maintainers may remove comments or block people who break these rules.

Report a problem with someone's behaviour by opening an issue that does not name them, or by contacting a maintainer through GitHub.

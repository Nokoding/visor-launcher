# Security

Visor Launcher has no INTERNET permission, so it cannot send anything off your TV. The permissions it asks for are listed in the README. The accessibility service (the PS style menu over other apps) is optional and off until you turn it on, and the README says what it reads and what it does not.

To report a security problem, open a private security advisory on GitHub (Security tab, "Report a vulnerability"). If that is not available, open an issue that says only that you have a security report, without the details, and a maintainer will answer. Please do not post exploit details in a public issue.

Updates are signed with the project's key. The SHA-256 of every release APK is in its release notes. Check it before you install: see the README.
